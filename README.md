# RoadSOS — True Input-Driven Prototype

The dashboard is generated from user-entered data. There are no pre-filled demo names, locations, emergency services, contacts, distances or safety tips.

## Data Setup
Use **Data Setup** to enter:
- user name, phone and location
- emergency services and their distance
- emergency contacts
- safety tip
- current incident details

The Home, Nearby Services and SOS screens render from that data. Data is stored in browser localStorage.

The emergency assistant is a built-in keyword-based demo, not an external AI service. Real GPS, service discovery, calling/SMS and backend persistence are not implemented yet.

Run with VS Code Live Server.
